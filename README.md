# Dukaio — Vendez vos produits digitaux en Afrique

Plateforme de vente de produits digitaux pour les créateurs africains (fichiers, cours, services, licences) avec encaissement Mobile Money et cartes bancaires.

## Technologies

- React 18
- Vite
- TypeScript
- Tailwind CSS
- Supabase

## Développement local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
